📅 Calendar Copy Extension

A Chrome extension to copy events from one date to another in Google Calendar

Installation Instructions

  1. Open Chrome and navigate to chrome://extensions/
  2. Enable "Developer mode" (toggle in top right)
  3. Click "Load unpacked"
  4. Select this folder
  5. The extension is now installed!
Note: This preview shows the extension popup UI. To use the actual functionality, install the extension in Chrome and use it on calendar.google.com
